## 🛠️ Getting Started

### Prerequisites
- Basic Python knowledge
- Python 3.x installed
- A code editor or IDE

### Installation
```bash
pip install numpy
```

### Your First NumPy Code
```python
import numpy as np

# Create your first array
marks = np.array([85, 90, 78, 92, 88])
print(f"Average marks: {np.mean(marks)}")
```
